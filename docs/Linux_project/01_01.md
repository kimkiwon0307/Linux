 # 1장 1교시 - Linux 서버의 역할과 구조

## 1. Linux와 Ubuntu
- Linux: 운영체제의 핵심인 커널(Kernel). 일반적으로 Linux 기반 운영체제 전체를 뜻하기도 함.
- Ubuntu: Linux 커널과 프로그램, 관리 도구 등을 묶은 Linux 배포판.
- Kernel: CPU, 메모리, 프로세스, 파일시스템, 네트워크 등 시스템 자원을 관리.

## 2. Linux 서버의 역할
- 웹 서비스 제공 및 애플리케이션 실행
- 계정·권한·보안 관리
- CPU·메모리·디스크·네트워크 관리
- 로그 분석, 백업, 장애 대응

## 3. 가상머신(VM)
- Host: VMware가 설치된 실제 컴퓨터 및 운영체제.
- Guest: 가상머신 내부에서 실행되는 운영체제.
- Hypervisor: 가상머신을 생성·실행하고 자원을 가상화하는 기술 또는 소프트웨어.
- vCPU: 가상머신에 할당되는 가상 CPU.

### VMware 사용 이유
1. 물리 서버 구매 없이 여러 서버 구성 가능.
2. 각 VM에서 독립적인 운영체제 실행 가능.
3. 스냅샷을 이용한 장애 복구 실습 가능.
4. 서버 구축·네트워크·스토리지 실습에 적합.

## 4. VM과 Docker의 차이
| 구분 | VM | Docker 컨테이너 |
|---|---|---|
| 운영체제 | VM별 Guest OS | 호스트 커널 기반 격리 |
| 커널 | VM마다 독립적인 커널 | 일반적으로 호스트 Linux 커널 공유 |
| 자원 사용 | 상대적으로 무거움 | 상대적으로 가벼움 |
| 용도 | 독립된 서버 환경 | 애플리케이션 실행 환경 |

※ 핵심: VM은 각각 자체 커널을 사용하고, 일반적인 Linux 컨테이너는 호스트 커널을 공유한다.

## 5. 프로젝트 구성
- linux01: 웹 서비스, 계정·권한·로그·보안 관리.
- linux02: 백업 및 모니터링.
- 환경: VMware Workstation + Ubuntu Server 24.04 LTS.

## 6. 면접 핵심 답변
Q. Linux 커널이란?
A. 하드웨어 자원을 관리하고 프로그램이 CPU, 메모리, 디스크, 네트워크 등을 사용할 수 있도록 지원하는 운영체제의 핵심입니다.

Q. VMware를 사용하는 이유는?
A. 한 대의 물리 컴퓨터에서 독립적인 운영체제를 가진 여러 가상 서버를 구축할 수 있고, 스냅샷을 활용해 장애와 복구를 안전하게 실습할 수 있기 때문입니다.

Q. VM과 컨테이너의 차이는?
A. VM은 각각 독립적인 Guest OS와 커널을 실행하지만, 일반적인 Linux 컨테이너는 호스트 커널을 공유하면서 프로세스를 격리합니다.
