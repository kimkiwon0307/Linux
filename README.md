# 우분투 리눅스

## 1장. 실습 환경 구축

> **개요:** 리눅스 실습의 기반이 되는 가상화 개념을 이해하고, VMware Workstation을 활용한 가상머신 환경 구축 및 특징을 학습합니다.

---

### 1.1 가상머신 소개와 설치

#### 1.1.1 가상머신 소개
* **가상화 (Virtualization):** 실제 컴퓨터 한 대를 여러 대처럼 효율적으로 나누어 쓰기 위해 탄생한 기술입니다.
* **가상머신 (VM, Virtual Machine):** 실제 컴퓨터 1대 안에서 동시에 독립적으로 실행되는 가상 컴퓨터들을 의미합니다. (ex. Ubuntu, Rocky Linux, Windows Server 등)

#### 1.1.2 가상머신과 가상머신 소프트웨어
* **하이퍼바이저 (Hypervisor):** 가상머신(VM)을 생성하고 관리하는 프로그램입니다.
* **대표 제품군:** `VMware`, `Hyper-V`, `KVM`, `VirtualBox`
* *참고:* 실무에서 가장 사용률과 선호도가 높은 **VMware**를 기준으로 실습을 진행합니다.

#### 1.1.3 VMware Workstation Pro 설치
* VM 생성 및 삭제, 복사, 네트워크 관리, 스냅샷 관리 등 가상 인프라 전반을 제어하는 핵심 도구입니다.

---

### 1.2 가상머신 생성

#### 1.2.1 가상머신의 구조
가상머신은 실제 물리 컴퓨터의 자원을 빌려와 가짜 하드웨어를 구성하는 원리로 동작하며, 구조적으로 완벽히 매칭됩니다.

| 실제 컴퓨터 자원 | 가상 머신 (VM) 자원 |
| :--- | :--- |
| CPU | **vCPU** (Virtual CPU) |
| RAM | **vRAM** (Virtual RAM) |
| SSD / HDD | **vDISK** (Virtual Disk) |
| NIC (랜카드) | **vNIC** (Virtual Network Interface Card) |

#### 1.2.2 가상머신 만들기
* **프로비저닝 (Provisioning):** VM을 생성할 때 하드웨어 자원(CPU, RAM, Disk, Network)과 설치할 운영체제(OS ISO 파일)를 할당하고 준비하는 일련의 과정을 말합니다.

---

### 1.3 VMware의 핵심 특징

1. **격리성 (Isolation):** VM(Ubuntu) 내부가 바이러스나 오류로 망가지더라도 호스트 PC(Windows)에는 전혀 영향을 주지 않습니다.
2. **복제 (Clone):** 이미 구성이 완료된 서버 환경을 그대로 복사하여 똑같은 서버를 빠르게 찍어낼 수 있습니다.
3. **스냅샷 (Snapshot):** 현재 정상적인 서버 상태를 저장(백업)해 두고, 문제 발생 시 언제든 해당 시점으로 되돌릴 수 있습니다.
4. **다중 실행:** 컴퓨터 한 대의 자원을 나누어 여러 서버(Web, DB, DNS 서버 등)를 동시에 띄우고 테스트할 수 있습니다.

---

### 1.4 원활한 실습 준비

#### 1.4.1 VMware 단축키 (Hot Key)
* `Ctrl + G` : 호스트(Windows)에서 VM 화면 안으로 마우스/키보드 제어권 넘기기
* `Ctrl + Alt` : VM 안에서 빠져나와 호스트(Windows)로 제어권 돌리기

#### 1.4.2 종료 옵션 (전원 관리)
* **Suspend (일시정지):** 현재 작업 상태를 그대로 메모리에 저장하고 멈춥니다. 빠른 재개에 유용합니다.
* **Power Off (강제 종료):** 실제 컴퓨터의 전원 플러그를 뽑는 것과 같으므로 데이터 유실에 주의해야 합니다.

#### 1.4.3 전체 화면 사용 및 여러 VM 동시 실행 기능 활용
* 실무 환경과 유사한 다중 서버 아키텍처 구성을 위해 여러 VM을 동시에 제어하는 방법을 숙지합니다.

#### 1.4.4 가상 네트워크 종류 파악

| 종류 | 인터넷 연결 여부 | 특징 및 통신 범위 |
| :--- | :---: | :--- |
| **Bridged** | ⭕ 가능 | 실제 PC와 동일한 네트워크 대역의 IP를 공유기에서 직접 할당받음. PC와 VM이 대등한 독립 장비로 동작. |
| **NAT** | ⭕ 가능 | **[실습 주력]** 호스트 PC 내부 IP를 공유받아 사용. VM에서 인터넷은 가능하나, 외부에서 VM으로의 직접 접근은 차단되어 보안상 유리. |
| **Host-Only** | ❌ 불가 | 외부 인터넷과 단절된 폐쇄망 구축 시 사용. 호스트 PC와 가상머신들 사이에서만 내부 통신 가능. |

#### 1.4.5 파일 전송 방법 (Windows ➔ Linux)
1. Drag & Drop (드래그 앤 드롭)
2. Shared Folder (VMware 공유 폴더 설정)
3. **SCP** (Secure Copy Protocol) 🌟 *실무 다빈도*
4. **WinSCP** (GUI 기반의 FTP/SFTP 클라이언트 프로그램) 🌟 *실무 다빈도*
