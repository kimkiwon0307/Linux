# 리눅스

## 리눅스 디렉터리 구조

/etc : 시스템/서비스 설정 파일
/var : 계속 변하는 데이터 로그, 캐시 등
/home : 일반 사용자 홈 디렉터리
/tmp : 임시 파일
/opt : 별도로 설치하는 프로그램을 두기도 함
/dev : 디스크, 터미널 같은 장치를 파일 형태로 표현
/proc : 프로세스와 커널 정보를 보여주는 가상 파일 시스템

## 절대경로와 상대경로
/ : 절대 경로
상대 경로 : 현재 위치를 기준으로
.. : 상위 디렉터리
. : 현재 디렉터리
~ : 사용자의 홈 디렉터리

## 파일과 디렉터리 기본 명령
현재 위치가 어디지? : pwd
여기 뭐가 있지? : ls
숨김 파일까지? : ls -la
디렉터리 이동 : cd
디렉터리 생성 : mkdir
빈 파일 생성 : touch
복사 : cp
이동/이름 변경 : mv
삭제 : rm

## 파일 내용 확인
전체 내용 간단히 확인 : cat
긴 파일 페이지 단위 확인 : less
앞 부분 확인 : head
마지막 부분 확인 : tail
실시간 로그 확인: tail -f

## 파일 찾기와 내용 검색
파일 자체를 찾음 : find
파일 안의 문자열을 찾음 : grep

## 파이프 | 
앞 명령어의 결과를 뒤 명령어의 입력으로 전달

## > 와 >>
덮어 쓰기 : >
뒤에 추가 : >>
